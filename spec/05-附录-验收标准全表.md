# 附录 · 验收标准全表（263 条 AC）

> 说明：`05-开发任务清单` 的每个任务引用若干 `AC-xxx`；本附录是这些编号的**唯一定义处**——QA 拿这一张表就能逐条跑，开发拿任务 ID 就能回查。
> 编号前缀与归属文件：`AC-DB/AC-SEED` → 01；`AC-AUTH/USER/META/TAG/SRC` → 02（S0/S1）；`AC-PARTNER/PLAN/FOLLOW/ATT/CONTACT/POOL/LEAD/DEAL/CH` → 02；`AC-FE` → 03；`AC-SUPPLY/TL/STAT/SEC/DEDUP/SORT/OFF/PUSH/TRACK/AUDIT/ADMIN/INFRA` → 04 或运维。
> 校验方式列写「人工」= 验收时人工核对；「接口」= 用 OpenAPI 控制台/脚本断言；「界面」= 真机操作；「SQL」= 查库断言。
