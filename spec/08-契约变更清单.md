## 1. `openapi.yaml` 需要改的行

### 1.1 新增端点

```yaml
# 追加到 paths 下（不是修改现有端点）
/users:
  get:
    tags: [meta]
    summary: 全员列表（A1 决策新增）
    security: [{ bearerAuth: [] }]
    parameters:
      - name: enabled
        in: query
        schema: { type: boolean, default: true }
        description: 默认只返回 ACTIVE；SALES 传 false 仍按 true 处理
      - name: q
        in: query
        schema: { type: string, maxLength: 40 }
        description: 模糊匹配 name / employee_no
    responses:
      '200':
        content:
          application/json:
            schema:
              allOf:
                - $ref: '#/components/schemas/ApiResponse'
                - type: object
                  properties:
                    data:
                      type: array
                      items: { $ref: '#/components/schemas/UserBrief' }
```

### 1.2 新增组件 schema

```yaml
components:
  schemas:
    UserBrief:
      type: object
      required: [id, name, role]
      properties:
        id:         { type: integer, format: int64 }
        name:       { type: string }
        dept:       { type: string, nullable: true }
        employeeNo: { type: string, nullable: true }
        role:       { type: string, enum: [SALES, ADMIN] }
        phoneMasked: { type: string, example: "138****6621" }
      description: 不含 password / lastLoginAt / 明文手机号
```

### 1.3 修改现有 schema

| 端点 | 子对象 | 改动 |
|---|---|---|
| `POST /partners`（#6） | request body | 加 `collaboratorIds: { type: array, items: { type: integer, format: int64 }, default: [] }` |
| `PUT /partners/{id}`（#8） | request body | 同上 |
| `GET /partners`（#5） | response item | 无需改（列表不返回协作人） |
| `GET /partners/{id}`（#7） | response | 加 `collaborators: [{ id, name }]` 数组 |

### 1.4 无需改动的部分

- 其余 50 个端点的方法、路径、参数全部不变。
- `GET /meta/dicts` 不含 users（用户不是字典），保持原样。

## 2. `V1__init.sql` 需要改的行

### 2.1 `org` 表加一列

```sql
CREATE TABLE org (
  ...
  owner_id        bigint      NOT NULL REFERENCES sys_user(id),
  collaborator_ids bigint[]   NOT NULL DEFAULT '{}',   -- ← 新增（C-01）
  created_by      bigint      NOT NULL REFERENCES sys_user(id),
  ...
);
```

**不需要**额外索引：一期没有「按协作人查合作商」的需求（PRD §8 未要求）。若二期要加，再建 GIN 索引 `USING gin(collaborator_ids)`。

### 2.2 其余 15 张表

**全部不变**。C-02…C-08 的字段（`lead_pool.claimed_*`、`follow.delete_reason`、`deal.closed_at`、`sys_user.pwd_changed_at`、`uk_org_credit_code`、`contact.role_tag`、`fk_plan_org`）**在 `01` 里已经写进 DDL**，本次只是正式把它们纳入契约，不产生 DDL 差异。

> 换句话说：`V1__init.sql` 相比 `v0.2-contract` 只有 **1 处新增列**。其余变更都是「把已写在 01 里的东西确认为契约」。

### 2.3 索引与视图

不变（仍是 PRD §12.2 的 9 条 + `v_partner_list`）。
