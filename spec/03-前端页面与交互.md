## 2. 屏 1 · 登录（`#login`）

**任务**：FE-PAGE-001（S0）

**结构**：Logo（58×58，渐变 `#22385F→#2C4C86`，字「商」）→ 标题「商旅分销 CRM」→ 副标「内部使用 · 上下游客户与供应商管理」→ 手机号输入 → 密码输入（密文 + 眼睛切换）→ 「登 录」主按钮 → 一行小字「忘记密码？」「未开通账号请联系管理员」→ 底部说明「本期仅支持手机号 + 密码登录 / 密码错误 5 次锁定 15 分钟」。

**组件**：`LoginHeader`、`FormField`（label + input）、`PrimaryButton`、`Toast`。

**数据来源**：`POST /auth/login`；`GET /meta/version`（登录页也可在启动时检查，见屏 10 版本信息）。

**状态**

| 态 | 表现 |
|---|---|
| 默认 | 手机号空、密码空；「登录」可点 |
| 加载 | 按钮转圈、禁点；不遮屏 |
| 错误 | 2002 → toast「手机号或密码错误」；2003 → toast「密码错误次数过多，请 15 分钟后再试或联系管理员」；网络错误 → toast「网络异常，请稍后重试」 |
| 无权限 | 不适用 |
| 已登录 | 冷启动若 refresh 有效，直接进 `partners`，不显示本屏 |

**交互**

| ID | 规则 |
|---|---|
| FE-LOGIN-01 | 手机号键盘为数字键盘；失焦校验 11 位；错误提示「请输入正确的手机号」并定位。 |
| FE-LOGIN-02 | 密码可切换明文。 |
| FE-LOGIN-03 | 点「忘记密码？」→ toast「请联系管理员重置密码」，不发请求。 |
| FE-LOGIN-04 | 登录成功：存 access/refresh（Keychain/Keystore）→ 拉 `GET /me` → 进 `partners`；清空密码框。 |
| FE-LOGIN-05 | 连续点击登录按钮防重（loading 期间禁用）。 |

**埋点**：`app_login{method:'password', success}`（客户端上报成功/失败各一次）。

**验收**：AC-AUTH-01/02/03/04 的前端侧各一条（格式校验、统一提示、锁定提示、停用提示）。

| 无权限 | 不适用（全员可见） |
| 离线 | 显示上次缓存列表（只读），顶部黄条「离线模式，数据可能不是最新」 |

## 12. 全局状态与异常（每屏都要实现的横切件）

| 状态 | 规格 | 组件 |
|---|---|---|
| 加载 | 首屏骨架 3 卡；按钮内 loading；列表翻页底部 loading | `SkeletonCard`、`LoadingMore` |
| 空 | 居中 3 行灰字 + 主行动按钮；不同场景文案见各屏 | `EmptyState` |
| 错误 | 顶部条「加载失败，点击重试」（保留旧数据）；首次失败给整页错误态 | `ErrorBar`、`ErrorState` |
| 无权限 | 403 → toast「没有权限执行该操作」；页面级 403 → 整页「暂无权限查看」+ 返回 | `Toast`、`ForbiddenState` |
| 离线 | 顶部黄条「离线模式，数据可能不是最新」；禁用需要联网的写操作（新建合作商、认领、采集） | `OfflineBar` |
| 会话过期 | 1002 → 尝试 refresh 一次；失败 → 清 token 回登录页并 toast「登录已过期，请重新登录」 | 请求层 |
| 服务端异常 | 5000 → toast「服务繁忙，请稍后重试」 | 请求层 |
